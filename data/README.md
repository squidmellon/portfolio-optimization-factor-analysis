# Data

## Raw data
The `raw/` folder contains the individual stock-price files used for the project:

- CI
- F
- IBM
- JNJ
- MU
- SHW
- WBD
- XOM

## Processed data
The `processed/` folder contains:

- monthly return data used in the portfolio analysis;
- the factor-regression dataset used by the Stata do-file.

GitHub can preview CSV files directly in the browser. Excel workbooks generally need to be downloaded to view all formulas, Solver settings, and worksheets.
